# The grade is decided in a bench and sent back as data

A grade is a visual judgement, and the only way to make one is to look at the picture while the
numbers move. The alternative this replaced was a round trip in prose: render a proof, watch it,
describe what is wrong in words, have that reinterpreted into parameters, render again. It loses
information at both ends — at "describe", because the vocabulary for a tonal fault is thin and
approximate, and at "reinterpret", because a number chosen from a sentence is a guess.

So the grade is decided in a browser tool with the picture in front of you and every reference read
live beside it, and what comes back is `look.json`, not a description. One file, the same one every
stage reads, with no translation step in between.

Two properties follow, and both are load-bearing.

**The tool's maths must predict the render.** A preview that drifts from the renderer is worse than
no preview, because it is confidently wrong. That is what the parity harness exists for, and why
the curve is generated by one program rather than ported into two.

**The emitted file must be complete.** `look()` has no fallbacks: a missing key stops the run rather
than substituting a different look. So a tool that emits a partial file has produced something that
aborts on the first read, which is the correct behaviour and the reason the bench carries every
block it does not itself edit through to its output verbatim.

## Consequences

- The grade is not editable in prose anywhere. A change to a look value that is described rather
  than sent is a change that has not happened.
- The vocabulary matters: what the bench shows is a **preview**, which is not a **proof**. See
  `CONTEXT.md`, which now separates them.
- The app in this repo is the same decision carried further: the engine stays dumb, the interface
  is where judgement happens, and the wire between them is data.

This was owed as a record by the precursor's own backlog and never written. `PROVENANCE.md` carries
why it is being written here instead.
